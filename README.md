# 🖼️ Interactive Image Processing App

A lightweight web application built with **Python**, **Streamlit**, and **Pillow** that allows users to upload images, inspect their underlying NumPy array dimensions, resize them dynamically, and download the processed files directly from the browser.

🔗 **Live Demo:** [Launch the App here](YOUR_STREAMLIT_APP_LINK_HERE)

---

## ✨ Features

- **Image Upload:** Supports `.jpg`, `.jpeg`, and `.png` file formats.
- **Array Inspection:** Converts uploaded images into NumPy arrays to display real-time data types and dimensional shapes (`Height, Width, Color Channels`).
- **Dynamic Resizing:** Interactive sliders allow users to customize width and height parameters between `50px` and `2000px`.
- **Instant Download:** Generates and exports the resized output (`nedu_image_resized.jpg`) with a single click.

---

## 🛠️ Tech Stack

- **[Python](https://www.python.org/)** – Core programming language
- **[Streamlit](https://streamlit.io/)** – Web application framework and UI
- **[Pillow (PIL)](https://python-pillow.org/)** – Image loading, manipulation, and resizing
- **[NumPy](https://numpy.org/)** – Array conversion and shape inspection
